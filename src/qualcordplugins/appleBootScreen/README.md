# AppleBootScreen Plugin für Qualcord

Zeigt beim Start von Discord einen minimalistischen, eleganten Apple MacBook Boot-Screen:
- Tiefschwarzer Bildschirm (`#000000`)
- Zentriertes, weißes Discord-Logo (oder wahlweise Apple-Logo)
- Dünner, abgerundeter Apple-Fortschrittsbalken
- Nahtlose, sanfte Überblendung (Fade-Out) direkt in den Discord-Chat
